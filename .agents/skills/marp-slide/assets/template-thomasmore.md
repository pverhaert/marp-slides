## 2. Code & Syntax Highlight

Voorbeeld van een semantisch HTML5-element met attributen:

```html
<picture>
  <!-- Moderne browser laadt WebP -->
  <source srcset="images/banner.webp" type="image/webp">
  <!-- Fallback voor legacy browsers -->
  <img src="images/banner.jpg" alt="Thomas More Campus" width="800" height="400">
</picture>
```

> ⚡ **Tip:** Gebruik altijd WebP en SVG voor optimale performantie op het web!

## 3. Tabellen & Vergelijkingen

| Formaat | Type | Compressie | Transparantie | Aanbevolen voor |
| :--- | :---: | :---: | :---: | :--- |
| **JPG / JPEG** | Raster | Lossy | Nee | Foto's en complexe beelden |
| **PNG** | Raster | Lossless | Ja (Alpha) | Screenshots, logo's |
| **WebP** | Raster | Beide | Ja (Alpha) | Moderne webstandaard |
| **SVG** | Vector | N.v.t. | Ja | Schaalbare iconen & illustraties |
